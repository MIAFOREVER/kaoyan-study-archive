## 教学顺序

| 顺序 | 内容与依赖 | 验收产出 |
|---|---|---|
| 1 | 链表：指针变量与 next 字段 → 保存后继 → 反转 → 边界 → 找中点、断链、交替合并 | 无提示复写反转并手推边界；再做 41 或同类新题 |
| 2 | Cache：字节/元素/块/行 → 直接映射与 Tag → 行列遍历 → 组相联地址拆分 | 完成 43 的过程及改参数新题，再复测 16；不能用直接映射公式忽略路数 |
| 3 | 树与查找：遍历还原 → BST 比较次数 → 哈夫曼 WPL → 散列探测 | 对应 5/6/8/7 的同类新题，必须有树图或探测过程 |
| 4 | 网络：子网范围 → TCP 字节序号/累计确认 → 窗口扣除未确认数据 → SR 序号空间 | 36/38/39/34 的新题；之后用 47 验证综合能力 |
| 5 | 图与算法性质：MST 与最短路径 → 拓扑排序；补复杂度与排序稳定性 | 对应 9/10/1/11；42 作为图综合诊断 |
| 6 | 组成剩余缺口：浮点编码；流水线数据产生/使用时刻、转发与停顿 | 对应 13/20；44 的独立时序分析 |

这不是要求一个模块全部学完才接触下一个。链表与 Cache 作为最先的两条线，短课交替、间隔复测；复杂度可穿插于算法讲解。顺序是基于当前证据的初排，新作答可以改变优先级。
