## 题目

给定一个带头结点的非循环单链表，请原地反转所有数据结点的顺序。

结点定义：

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

请实现：

```c
void reverse(Node *head);
```

约定：head 一定指向一个有效的头结点 H，H 不存放有效数据元素。输入链表无环，以 NULL 结尾；空表为 `head → H → NULL`。本题不要求处理 `head == NULL` 的无效输入。

例子：

```text
反转前：head → H → 1 → 2 → 3 → 4 → NULL
反转后：head → H → 4 → 3 → 2 → 1 → NULL
```

要求：

1. 保留原头结点 H，头结点不参与数据结点的反转。
2. 只能改变结点间的链接，不能交换 data，不能申请或释放结点。
3. 时间复杂度 O(n)，额外空间复杂度 O(1)，n 为数据结点数。
4. 正确处理空表、只有一个数据结点和多个数据结点；结果仍以 NULL 结尾。
