## 题目

给定一个带头结点的非循环单链表，请原地反转所有数据结点的顺序。

结点定义：

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

请实现：

```c
void reverse(Node *head);
```

约定：head 是 `Node *` 指针变量，保存头结点 H 的地址；H 才是实际存在的一个 Node 对象，不存放有效数据元素。head 本身不是另一个链表结点。输入链表无环，以 NULL 结尾；空表为 `head（指针变量） → [H] → NULL`。本题不要求处理 `head == NULL` 的无效输入。

例子：

```text
反转前：head（指针变量） → [H] → [1] → [2] → [3] → [4] → NULL
反转后：head（指针变量） → [H] → [4] → [3] → [2] → [1] → NULL
```

方括号表示结点。第一个箭头表示 head 保存 H 的地址，后续箭头表示各结点的 next 链接。前后 head 都指向同一个 H；H 的 next 从指向结点 1 改为指向结点 4。

要求：

1. 保留原头结点 H，头结点不参与数据结点的反转。
2. 只能改变结点间的链接，不能交换 data，不能申请或释放结点。
3. 时间复杂度 O(n)，额外空间复杂度 O(1)，n 为数据结点数。
4. 正确处理空表、只有一个数据结点和多个数据结点；结果仍以 NULL 结尾。
