## 两个名字分别指什么

- 主存块：主存按固定大小划分的一段连续数据，例如前例的 A[0..7] 所在块。
- Cache 行：Cache 中用于保存一个主存块数据及相应管理信息的存储单元。当前先计算其数据部分，标记、有效位等稍后讲。

主存块是要保存的那份数据；Cache 行是 Cache 中承载它的位置。一行同一时刻最多保存一个主存块的数据，之后可以被其他块替换。

## Cache 能同时保存多少块

假设 Cache 数据区容量为 256 B，每块为 32 B：

```text
行数 = Cache 数据区容量 ÷ 块大小
     = 256 ÷ 32 = 8 行
```

可以把数据区看成 8 个存储位置，每个位置容纳一个 32 B 块的数据，最多同时保存 8 个主存块的数据副本。

这里的“8 行”不是指主存只有 8 块，也不是指 Cache 只能存 8 个整数。每个 int 若为 4 B，一行的 32 B 数据区能装 8 个整数。

容量 256 B 已明确是数据区容量，不把标记、有效位等额外信息算入本次除法。至于某个主存块能放在哪一行，取决于映射方式，下一步再讲。

之前的例题假设调入后不会被替换。之后学习真实的有限容量与映射约束时，要检查块当前是否仍在对应位置，不能仅凭以前访问过就断定命中。
