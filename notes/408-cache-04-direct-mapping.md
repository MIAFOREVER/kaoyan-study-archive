## 一个主存块能放在哪一行

采用直接映射时，每个主存块只能放入指定的一行：

```text
Cache 行号 = 主存块号 % Cache 行数
```

% 表示除法的余数。本例为主存块号 % 4。主存块从0开始编号，块号不是数组下标，也不是字节地址；本轮直接给出块号，不计算地址。

| Cache 行号 | 可以映射到此行的主存块号 |
|---|---|
| 0 | 0、4、8、12、…… |
| 1 | 1、5、9、13、…… |
| 2 | 2、6、10、14、…… |
| 3 | 3、7、11、15、…… |

多个块被分配到同一行，但一行同时只能保存其中一个块的数据。

## 空着的其他行也不能随便放

Cache 初始为空，先读取主存块1中的数据：未命中，将块1装入第1行。

接着读取主存块5中的数据：5%4=1，也只能放第1行。该行当前存的是块1，不是块5，所以未命中，块5替换块1。即使第0、2、3行仍空着，直接映射规则也不允许把块5改放在那里。

```text
读块1后：第1行保存块1
读块5后：第1行保存块5，块1的数据副本已被替换
```

这就是映射冲突造成的替换。之前“调入后不被替换”的假设在本轮不再沿用：访问过的数据可能已不在 Cache 中。主存里的原块并没有因此被删除；这里讨论的是 Cache 中的数据副本。

判断命中要看指定行里当前是否有目标块的有效数据，不能只看这一行是否非空。如何通过标记判断是哪一块，下一步再讲。
