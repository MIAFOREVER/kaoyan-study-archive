## 先分清两个操作

```c
cur = next;        // 改变变量 cur 保存的地址：让 cur 指向另一个结点
cur->next = prev;  // 改变 cur 指向的结点里的 next 字段：修改链的连接
```

第一句不会改动任何结点的 next 字段；第二句才改变链表结构。指针赋值也不会复制整个结点。

以带头结点的 `H → 1 → 2 → 3 → NULL` 为例，头结点 H 不参与数据结点的反转。初始化 `prev = NULL`、`cur = H->next`，让 cur 指向 1。

第一轮执行：

```c
Node *next = cur->next; // next 保存结点 2 的地址
cur->next = prev;       // 将 1 的 next 改成 NULL
prev = cur;            // prev 指向 1
cur = next;            // cur 指向 2
```

这时，以两个工作指针为入口观察：

```text
prev → 1 → NULL       已反转部分
cur  → 2 → 3 → NULL   尚未处理部分
```

中途 H->next 仍指向 1，尚未更新为新首结点。整个循环结束后，才令 `H->next = prev` 连接反转后的首结点。

如果在保存后继之前执行 `cur->next = prev`，1 原本通向 2 的链接就被覆盖。之后再从 `cur->next` 读取，得到的是修改后的值；无法靠这条链接继续找到原后半段。
